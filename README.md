# ATM10 Server Pack

Client pack definition for our All the Mods 10 server (Minecraft 1.21.1, NeoForge 21.1.251).

This repo holds packwiz metadata only — no mod files. Mods download from
CurseForge and Modrinth automatically on launch.

## Setup

1. Install [Prism Launcher](https://prismlauncher.org/)
2. Import the instance zip (ask Jacob)
3. Sign in with your Microsoft account
4. Hit Play — mods sync automatically on every launch

Updates apply themselves. You never need to download anything manually.
